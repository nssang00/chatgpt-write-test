# v58.5.2 r5 — Unity WebView2 Stage2 실기 검토 절차

**현재 기준(2026-10-13 23:08 결과):** Unity Player 빌드 PASS, 자동 한글+이모지 Echo 1회, 수동 Echo ACK 1회, 메시지 거부 0회, 종료 정리 PASS(약 0.05초). 단, 수동 ACK는 입력한 내용이 **직접 타이핑한 새로운 한글 문장인지** 증명하지 않습니다. IME 후보창·포커스·창 좌표·DPI 화면 증거도 없습니다.

**목표:** 아래 R01~R09를 실제 Windows PC에서 직접 관찰하고 증거를 남깁니다. 자동 PASS ≠ Stage2 전체 PASS ≠ 정식 WebView2 Backend 출시 승인입니다.

## 1. 준비 및 실행

1. 이 Stage2-review-kit ZIP을 새 폴더(예: D:\wv2-review-r5)에 압축 해제하세요. CEF v58.4.4 OneClick 폴더에는 넣지 마세요.
2. Unity 2022.3.62f3 + Windows Build Support, Unity 라이선스, WebView2 Runtime, 드라이브 여유 공간 10GB 이상을 준비하세요.
3. Windows에 Microsoft 한국어 IME를 설정하세요. 가능하면 배율이 다른 두 모니터(100%와 150% 등)를 사용하세요.
4. **Review-Stage2.cmd** 더블클릭 → 열리는 가이드를 확인 → 콘솔에 START 입력.
5. Unity Player가 약 **180초** 표시됩니다. 아래 R01~R07, R09를 테스트하세요. 시간이 부족하면 Review-Stage2.cmd -AutoSeconds 300 을 사용하세요(최대 300초).
6. **Player를 일찍 종료하지 마세요.** 자동 종료·정리 이후 콘솔에서 각 항목을 P=PASS / F=FAIL / N=NOT_TESTED로 기록합니다. 모르는 항목은 N입니다.
7. 결과 ZIP은 results 폴더의 stage2-review-날짜.zip으로 생성됩니다.

|---|---|---|---|

**버튼 구분:** Native ping은 항상 고정 문자열 probe-pong을 반환합니다. 실제 입력한 한글은 **Send to Native Echo**를 눌러야 전송됩니다.

**IME 관찰:** 조합 중 후보창과 커서가 정확히 입력 영역 근처에 떠야 하며, 최종 확정된 한글에 깨짐이나 중복이 없어야 합니다.

**범위 제외:** 단일행 HTML input만 시험합니다. 여러 줄 텍스트박스, 붙여넣기 보안, 복잡한 폼, 다중 WebView, UGUI가 브라우저 위에 표시되는 제품 요구사항은 별도 검증입니다.

## 3. 검토 결과 및 판정

- 자동 검증 실패: 수동 PASS를 입력하더라도 **단계 통과 불가**. 자동 ZIP을 제출하고 오류 분석.
- 모든 항목 PASS: **MANUAL_REPORTED_PASS_PENDING_EVIDENCE_REVIEW**(자가 보고 성공, 사진/증거 검토 대기).
- 하나라도 FAIL: **MANUAL_REPORTED_FAIL**(재현 설명/화면 캡처와 함께 제출).
- 하나라도 NOT_TESTED: **MANUAL_PARTIAL**(미검증 항목이 남음).
- 정식 판정은 어떤 경우에도 **PENDING_INDEPENDENT_REVIEW**. 사람이 보고한 체크만으로 Stage2 PASS_FULL, CEF 교체, 정식 출시가 이뤄지지 않습니다.

## 4. 제출할 증거

1. **results/stage2-review-날짜.zip** 하나(자가 체크리스트와 기존 Unity/Player 로그).
2. 민감한 정보를 가린 스크린샷 **2~4장**: 한글 입력과 Echo 결과, 조합 후보창, 창 리사이즈/다중 DPI.
3. R08의 경우 반복 실행으로 만들어진 별도 자동 결과 ZIP 2개(가능한 경우).
4. Windows 버전, 사용 IME 종류, GPU, 모니터 배율·해상도를 간단히 적어 주세요.

**주의:** 이 도구는 입력한 문장 원문, 브라우저 쿠키/프로필, 화면을 자동 수집하지 않습니다. 로그에는 로컬 경로 등 환경 정보가 남을 수 있으니 공유 전 확인하세요.

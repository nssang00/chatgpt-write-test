# KiteFiles v2.3 improvements

Built on the previously validated v2.2 code. Changes preserve SMB2/3 and file-engine behavior.

- 59dp folder rows (51dp in compact view), 40dp folder icons (33dp compact).
- Full real folder paths in the top bar and tab chips. Removed redundant `내 파일` breadcrumb badge.
- Atomic navigation: denied/unreadable folder does not change breadcrumb/current folder until listing succeeds.
- Meaningful Android 11+ `Android/data` and `Android/obb` protected-folder explanation.
- Directory shortcuts no longer race against pending background listing.

Artifact: `KiteFiles-v2.3-compact-path-debug-apk`.
Platform restrictions: even MANAGE_EXTERNAL_STORAGE cannot access other apps' protected data directories. Build + UI smoke is distinct from real-device behavior.

## Interpretation and limitations

On this specific setup, OpenLayers reaches its completion event sooner (for all-layer zoom 16 P50: 147.8 ms vs 413.1 ms). This is a **time-to-settle measurement**, not proof that OpenLayers' GPU commands render ~2.8x faster. The two completion events have different semantics; the rendering stacks also differ: MapLibre uses multiple style layers and OpenLayers one WebGLVectorTileLayer with 18 style rules. Fonts, labels, icons and interactivity are excluded. The results include fetch/parsing/layout/worker/GPU scheduling. There is some tail-latency reversal: the all-layer zoom14 OpenLayers P95 is 584 ms, above MapLibre's 439.5 ms.

Screenshots for each area/engine at zoom16 were retained in the ZIP; Gangnam's geographic extents visually match after correction. For an isolated GPU drawing-speed comparison, profile GPU timing and repeat with matched independent layer/styling costs.

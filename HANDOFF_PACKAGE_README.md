## Current implementation focus

The current repository already contains:

- direct xytron.foo() JavaScript facade + invoke compatibility
- worker-pool JS -> C++ dispatch
- RequestId-correlated typed std::future completion
- root/native object binding and object registry
- Linux/Windows CEF + Windows WebView2 real-browser regressions
- Callable/signature metadata + BindingRegistry
- generation-safe RegistrationToken
- cross-platform SharedLibrary
- stable C ABI v1 PluginModule function registration
- C++ Plugin/PluginApi/NATIVEWEB_PLUGIN convenience wrapper
- plugin callable and queued/running task module lease
- generic native-object owner-lease foundation

The plugin-created native-object ABI, argument-aware factory registration,
conservative unload/plugin_busy behavior and asynchronous object lifetime are
implemented in this local source lineage. The current priority is to run the
new real-browser plugin E2E on CEF and WebView2 CI runners; the browser
check has not yet been executed in this local environment.

See `docs/BROWSER_PLUGIN_E2E.md` and `.github/workflows/browser-plugin-e2e.yml`.
GitHub baseline commit metadata refers to the original handoff snapshot;
these local changes have not been pushed to the upstream repository.
